# Изображения бота

Картинки, которые бот отправляет в сообщениях или использует в оформлении.
Папка `assets/` входит в git и копируется в Docker-образ (`/app/assets/images/...`).

| Папка          | Что класть                                       |
| -------------- | ------------------------------------------------ |
| `banners/`     | Баннеры к сообщениям: акции, рассылки, промо     |
| `logos/`       | Логотипы проекта, партнёров, платёжных систем    |
| `icons/`       | Иконки и мелкие картинки                         |
| `backgrounds/` | Фоны и подложки (например, для генерации картинок) |

## Как отправить из кода

```python
from pathlib import Path

from aiogram.types import FSInputFile

IMAGES_DIR = Path(__file__).resolve().parents[N] / 'assets' / 'images'  # N — сколько уровней до корня

await message.answer_photo(FSInputFile(IMAGES_DIR / 'banners' / 'new-year-2027.jpg'), caption='...')
```

## Правила

- **Имена:** `kebab-case`, латиница, без пробелов: `summer-sale.jpg`, `partner-platega.png`.
- **Форматы для `send_photo`:** `jpg`, `png`, `webp`. **SVG Telegram как фото не принимает** —
  храните SVG как исходник, а для отправки экспортируйте в `png`.
- **Размер фото:** до 10 МБ, сумма ширины и высоты — не больше 10000 px,
  соотношение сторон — не больше 1:20. Оптимально для баннера: 1280×720 (16:9), до ~500 КБ.
- Логотип главного меню сюда **не** переносится: это `vpn_logo.png` в корне репозитория
  (путь задаётся в `LOGO_FILE` и пробрасывается volume'ом в `docker-compose.yml`).
- Картинки из этой папки попадают в образ при сборке. Чтобы поменять картинку без
  пересборки, подключите папку volume'ом: `- ./assets/images:/app/assets/images:ro`.
